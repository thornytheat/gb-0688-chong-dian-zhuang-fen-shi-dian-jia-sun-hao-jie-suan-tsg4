# 电量与费用定义

id为计量号、order为订单号、station为站点，均为字符串。kind取order或station。计量start/end必须带时区，区间[start,end)，最大72小时可调至168小时。energy以kWh或MWh输入，输出kWh。未知哨兵不等于零。
费率版本以本地+08日期[from,to)生效；日内时段必须完整无重叠覆盖0–24小时。默认11月17日调整尖峰价，可在API参数tariffs中提供相同结构版本清单。
计量段内假定匀速用电，电量按时长交集分配，最后一段修正Decimal除法尾数保证电量严格守恒。跨日以当地日期重选版本。

## 反向放电（direction）

订单行可选direction列，取charge（充电，缺省）或discharge（放电）；总表行强制charge。放电量以绝对值记录，方向决定其在净额与损耗中的符号。未提供该列的旧数据全部按充电处理，行为与历史版本一致。
总表只计量充入与放出相抵后的净电量。定义：充电量C、放电量D（均为正数）、总表净量M，则站级损耗 L = M − (C − D)。直接按净电量整站分摊会让放电单替充电单承担损耗，因此损耗先按方向切分：充侧 Lc = L·C/(C+D)，放侧 Ld = L − Lc；各方向内部再按订单电量占比分摊到单，尾差并入末单。放电单只承担放侧损耗。

## 同站按日日结（M8）

以+08:00本地日把每条计量按时长切到“站点×日期”，每份日结同站同日唯一。日结恒等链：总表净量 = 充电量 − 放电量 + 损耗合计；损耗合计 = 充侧损耗 + 放侧损耗；同方向订单损耗份额之和 = 该方向站级损耗。任一守恒不成立抛INCOMPLETE，整批不落库。
负损耗（订单净额超过总表）、总表缺失/重复、总表未覆盖订单当日区间、无订单承接损耗均标记异常且不分摊损耗，账单与日结结论为待复核；代数恒等在异常态仍成立。
入库由POST /api/m8/settle显式触发，预览接口/api/m8只算不写。每份日结带站点×日期独立输入摘要：相同输入重试返回“幂等”不新增版本；晚到放电单只重算受影响的站点×日期，旧版先归档再原子替换；存储失败整体回滚恢复旧版日结并记录“重算失败”事件；已复核（通过/退回）日结锁定，后续重算返回“锁定”且原样保留，历史版本可按版本号取回。

每站唯一总表电量减订单净额为损耗，按订单kWh占比分配。总表缺失、重复、负损耗或无订单承接损耗时标记异常，不强行分配。
订单应收=各分时电量×费率+损耗份额×loss_rate。先算站总额再最大余额分币，稳定id打破余数并列。JSON金额为Decimal字符串。账单bill为CNY，差额=应收-bill，容差边界包含。
版本最高者采信，同版冲突全部隔离；重复和旧版计入隔离。输入行数=采信+隔离。批次哈希包含输入摘要、规则版本、参数；复核乐观锁防止旧提交覆盖。

站点总表区间必须覆盖其全部订单区间；未覆盖标记总表未覆盖订单区间，损耗不强制分摊，账单结论为待复核。
