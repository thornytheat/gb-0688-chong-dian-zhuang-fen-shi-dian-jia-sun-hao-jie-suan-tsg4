# 充电桩分时电价与损耗结算

使用者：充电站财务核算员。接收计量间隔与订单，按实际时段重算电费及站内损耗。

核心规则：电量按计量段与费率区间交集时长分配，跨日费率按当地日期选择，未知电量不作零，损耗分到分。站点接入反向放电后，总表只记充抵相抵净电量，订单分充电/放电，损耗按方向切分后同站按日唯一结算并可逐级追溯。

## 启动

```sh
docker compose up --build -d
docker compose exec -T app pytest -q
docker compose config --quiet
```

浏览器访问 http://localhost:18202 。首页已装载脏样例，可编辑CSV与参数后运行，也可上传文件。八个导航分别对应业务步骤。

## 模块

- M1 电量接收：接收订单及总表计量（含可选direction列），入口 `/m/1`、`GET/POST /api/m1`。
- M2 费率版本：校核费率版本、单位与充放方向，入口 `/m/2`、`GET/POST /api/m2`。
- M3 订单切段：按时段交集拆分电量，入口 `/m/3`、`GET/POST /api/m3`。
- M4 站内损耗：按站点分向分配总表损耗，放电单不替充电单承担，入口 `/m/4`、`GET/POST /api/m4`。
- M5 费用重算：精确计算并分配分币，入口 `/m/5`、`GET/POST /api/m5`。
- M6 账单对照：对照账单与损耗异常，入口 `/m/6`、`GET/POST /api/m6`。
- M7 结算批次：核对电量行数并复核，入口 `/m/7`、`GET/POST /api/m7`。
- M8 充放日结：同站按日唯一可结算，分向损耗与守恒追溯、版本归档与复核锁定，入口 `/m/8`、`GET/POST /api/m8`、`POST /api/m8/settle`。

## 反向放电与日结

订单行用 `direction=charge|discharge` 标记方向（缺省charge），放电量记绝对值。M8按+08本地日切分，恒等链 `总表净量 = 充电量 − 放电量 + 损耗`，损耗先按充/放电量占比切向再分摊到单。`sample_data/bidirectional.csv` 为充放电样例。

入库在M8页面或 `/api/m8/settle` 显式触发：相同输入重试幂等不新增版本；晚到放电单只重算受影响的站点×日期并归档旧版；重算失败事务回滚恢复旧版日结；已复核日结锁定不覆盖，历史版本与事件可查。

## 演示与复核

1. 运行默认样例，核查隔离原因与业务合计。
2. 修改CSV单元格或参数并重跑，保留行号与输入摘要。
3. 在最后一步复核，旧版本提交返回409。
4. 证据CSV包含采信行和隔离行，重跑相同内容复用批次。
5. 用 `bidirectional.csv` 在M8入库，追加一条晚到放电单后再次入库，观察仅相关日结重算、版本归档与事件。

## 数据与目录

`app/modules/` 按业务切分；`sample_data/` 为UTF-8 BOM、GB18030及干净/脏/充放电样例；`tests/` 含规则与端到端测试。SQLite保存运行、复核与日结（含版本归档、事件），命名卷records保留重启后的记录。若需从头开始，可先停止服务并在确认不再需要记录后删除该项目records卷。

## 定义与边界

计量段内假定匀速用电，站点总表必须唯一且覆盖所导入的全部订单；真实采样差异应预先切成计量段。只计算电费及损耗，不含停车服务费。日结按+08本地日归组，跨日订单按时长切到各日。

详细字段、计算定义与原因码见 `docs/DATA-DICTIONARY.md`，回归证据见 `docs/DEPTH.md`。
